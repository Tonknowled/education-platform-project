# Учебная платформа (Education Platform)

Проект представляет собой backend-часть учебной платформы для онлайн-курсов. 
Разработан в рамках итогового проекта по ORM и Hibernate.

## 🛠 Стек технологий
- Java 17
- Spring Boot 4.2.0
- Spring Data JPA (Hibernate 7)
- PostgreSQL 16
- Maven

## 🚀 Как запустить

1. Установите PostgreSQL и создайте базу данных:
   ```sql
   CREATE DATABASE education_platform;
